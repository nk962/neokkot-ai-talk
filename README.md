## 3. 새 디자인의 재료

### 장표 색 (그대로 유지)

나윤님 작업본의 읽어주세요.txt와 굽기 도구(build.py)에 정해진 색만 씁니다. 학원 사이트의 남색과 코랄은 쓰지 않았습니다.

| 색 | 코드 | 쓰는 곳 |
|---|---|---|
| 주황 | #FF6A00 | 강조 낱말, 이름표, 번호, 알약 |
| 글자 | #1F1B18 | 본문 글, 어두운 카드, 장 나누기 바탕 |
| 회색 | #6B6560 | 보조 글, 꼬리 줄 |
| 바탕 | #F6F4F1 | 모든 장의 바탕 |
| 선 | #E4E0DB | 구분선, 장 나누기의 큰 번호 |
| 흰색 | #FFFFFF | 카드 |
| 연회색 | #9C958E | 두 색 문장의 흐린 부분 |
| 옅은 회색 | #C9C3BC | 어두운 카드 안 보조 글 |

연회색 두 가지는 나윤님 굽기 도구가 이미 쓰던 색입니다. 예외는 카톡 화면 흉내 9장의 노랑(#FEE500)과 하늘색(#8FA7BC, #B2C7D9) 하나뿐입니다. 화면이 카톡처럼 보여야 해서 그대로 뒀습니다.

### 글꼴 (youareflower.com에서 가져옴)

학원 사이트가 쓰는 글꼴 두 가지를 그대로 씁니다. 굵기는 사이트보다 한 단계씩 낮췄습니다.

| 글꼴 | 사이트 | 장표 |
|---|---|---|
| Paperlogy | 제목, 8 ExtraBold | 제목과 굵은 글은 7 Bold, 작은 굵은 글과 알약은 5 Medium, 장 나누기 큰 번호는 4 Regular |
| KoPub World 돋움 | 본문, Light | 본문, Light 그대로 |

자간은 모든 글에 -0.02em입니다. 글꼴 파일은 저장소 `fonts` 폴더에 들어 있어 인터넷 글꼴 서버가 막혀도 그대로 보입니다. Paperlogy는 누구나 무료로 쓸 수 있는 OFL 글꼴이고, KoPub World 서체는 한국출판인회의가 무료로 나눠 주는 글꼴입니다.

## 4. 검수

### 여백 검수 (432장 전부)

기준은 다섯 가지입니다. 글과 그림은 왼쪽 120px, 오른쪽 1800px 안에 들어가야 합니다. 머리 줄 아래와 꼬리 줄 위에 8px 넘게 띄워야 합니다. 화면 밖으로 나가면 안 됩니다. 글이 상자에 잘리면 안 됩니다. 글자를 80%보다 작게 줄인 장이 없어야 합니다.

결과: 432장 모두 통과했습니다. 431쪽(prog-09) 한 장만 내용이 많아 글자를 76%로 줄였는데, 찍어 보니 읽는 데 문제가 없어 그대로 뒀습니다.

검사 중에 고친 곳은 두 군데입니다. 73쪽 드라이브 이름표가 왼쪽 여백 밖으로 나가서 안으로 옮겼습니다. 98쪽은 머리말이 머리 줄에 붙어서 아래로 내렸습니다.

### 디자인 검수 (432장 전부, 원본과 나란히)

방법: 432장을 12장씩 한 판으로 찍어 원본 판과 나란히 놓고 봤습니다. 볼 것은 세 가지였습니다.

- 뜻이 사라지거나 바뀐 곳
- 균형: 빈 곳, 한쪽으로 몰린 곳, 지나치게 작거나 큰 글, 어색한 줄바꿈, 같은 흐름에서 위치가 튀는 곳
- 겹침, 잘림, 장표 밖 색

첫 검수에서 문제 없음은 273장, 고칠 곳이 있는 장은 159장이었습니다. 원인은 열 가지로 모였고 모두 고쳤습니다.

| 원인 | 고친 방법 |
|---|---|
| 굵게 강조한 낱말이 가늘게 보임 | 본문 속 굵은 낱말은 Paperlogy Bold로 |
| 시간·라벨과 내용이 화면 양 끝으로 갈라짐 | 원본의 라벨 칸 너비와 줄 구분선을 살림(매일 10:00, 하는 일 등 28곳) |
| 회색 문장이 너무 흐림 | 회색은 진한 회색(#6B6560)이 기본. 진한 글과 함께 놓인 두 색 문장에서만 연회색 |
| 같은 흐름에서 위치가 튐 | 내용이 짧은 장은 모두 왼쪽 아래에 앉힘 |
| 소항목 장이 장 구분처럼 보임 | 첫 번째·두 번째 같은 소항목 22장은 밝은 바탕에 주황 큰 번호로. 검은 부 나눔은 강연 7부를 여는 7장(25, 49, 146, 172, 233, 279, 414쪽)에만 PART 01~07로 |
| 주황 낱말 하나뿐인 장이 텅 빔 | 왜 쓰는가, 가설, CLOSING 같은 13장은 주황 큰 제목으로 |
| 글로만 짠 목록의 글씨가 작음 | 카드·그림 없는 목록 49장은 글을 한 단계 키움 |

- 35, 37, 74쪽 같은 몇몇 장은 줄바꿈이 뜻 단위 중간에서 끊깁니다. 브라우저의 줄 나눔을 다듬었지만 장마다 직접 끊지는 않았습니다.

## 6. 고쳐서 다시 굽기

`source` 폴더에 내용과 굽기 도구가 있습니다. 굽기 도구를 돌리려면 파이썬 3이 있어야 합니다.

- `content.json`: 432장의 글, 그림, 짜임. 글을 고칠 때는 content.json을 고칩니다
- `theme-b.css`: 색, 글꼴, 카드 모양 같은 디자인
- `template.html`: 장 넘기기와 화면 맞춤
- `keep.txt`: 원래 배치를 살린 장 목록

다시 굽기: `python3 source/render.py source/content.json assets <출력 폴더> b`
