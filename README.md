## 4. 188쪽으로 모은 방법과 확인

- 장 이름이 같은 흐름(origin, origin-2, origin-3)이거나, 머리말이 없거나 같은 머리말인 바로 다음 장을 한 쪽에 모읍니다. 한 쪽 높이를 넘지 않을 만큼만 모읍니다.
- 한 쪽에 모인 둘째 장부터는 넘길 때마다 차례로 나타납니다. 발표 흐름과 순서는 원본과 같습니다.
- 첫 번째, 두 번째 같은 소항목 장은 다음 장 제목 위에 붙였습니다.
- 한 쪽에 같은 글이 두 번 나오면 하나만 남겼습니다.
- 강연 7부를 여는 장, 표지, 폰 화면, 수업 영상 장, 원래 배치 2장은 따로 둡니다.
- 표지 날짜 줄은 첫 표지에만 남겼습니다. 한 줄짜리 장(2025년과 2026년, 현재까지)은 셋째 표지의 숫자 아래로 옮겼습니다.

한 쪽에 모인 장 수는 1장 71쪽, 2장 53쪽, 3장 25쪽, 4장 18쪽, 5장 12쪽, 6장 5쪽, 7장 2쪽, 9장 2쪽입니다.

확인은 두 가지로 했습니다.

1. 446장의 글 줄 하나하나가 구운 페이지 코드에 있는지 맞췄습니다. 빠진 줄은 0줄입니다.
2. 크롬에서 차례로 나타나는 글을 모두 펼친 뒤, 화면에 실제로 보이는 글로 다시 맞췄습니다. 원본 102번 장의 폰 화면 속 글 1줄만 걸렸습니다. 브라우저 보안 때문에 폰 화면 속 글을 바깥에서 읽을 수 없어서입니다. 1번 검사에서는 폰 화면 속 글도 들어 있습니다.

### 화살표와 카톡 화면

- 화살표는 원본 방향 그대로 그립니다. 중요도, 귀찮음, 반복은 주황 위 화살표, 난이도는 회색 아래 화살표입니다. 네 가지를 한 줄 카드로 놓았습니다.
- 단계를 잇는 흐름은 칸마다 흰 카드에 넣고 주황 화살표로 잇습니다.
- 카톡 노란 말풍선은 오른쪽에 붙이고, 방 이름 띠는 하늘색 둥근 띠로 그립니다.
- 폰 화면은 오른쪽, 제목은 왼쪽에 두어 서로 가리지 않습니다.

### 수업 영상

- 원본 영상(HEVC)을 어느 브라우저에서나 재생되는 H.264로 바꿨습니다. 1600×762, 47초, 2.6MB입니다.
- 쪽을 열면 영상을 미리 받아 둡니다. 영상을 누르면 재생되고, 다른 쪽으로 넘기면 멈춥니다.
- 실제 주소에서 크롬으로 확인했습니다. 10초 동안 294프레임 가운데 2프레임, 다른 확인에서는 144프레임 가운데 0프레임이 끊겼습니다.

## 7. 확인 부탁

1. **새로 넣은 9장의 위치**: 수정본 PDF 17~25쪽은 자료는 누구나 갖게 됩니다로 시작해 한 줄 정리로 끝납니다. 원본에 같은 글이 없어서, 내용이 이어지는 학생이 느끼는 퀄리티 장 뒤에 넣었습니다. 다른 곳이면 알려 주세요.
2. **원본 357~360번 장의 작은 글**: 가운데 큰 글 위아래에 주간내신, 주간 모의고사 같은 작은 글이 있었습니다. 표를 고치다 남은 칸 조각(`<td>`)으로 보여 뺐습니다. 일부러 넣은 글이면 알려 주세요.
